# Obsidian Kanban Plugin

> [!NOTE]
> **This is a community-maintained fork** of [Kanban](https://github.com/community-archive/obsidian-kanban), while the original looks for new maintainers ([#1182](https://github.com/community-archive/obsidian-kanban/issues/1182)). It fixes bugs only: no new features or settings, the same plugin ID, and the same board format, so your boards and settings carry over unchanged. See the [releases](https://github.com/dev-ankit/obsidian-kanban/releases) for what's fixed, and [CREDITS.md](CREDITS.md) for the people who reported and fixed the bugs.
>
> **Install it with BRAT**
>
> 1. Install and enable [BRAT](https://obsidian.md/plugins?id=obsidian42-brat) from Community plugins.
> 2. Run **BRAT: Add a beta plugin for testing**, enter `dev-ankit/obsidian-kanban`, and choose the latest version.
> 3. BRAT replaces your installed Kanban with this build. Your boards don't change.
>
> **Go back to the official version:** remove `dev-ankit/obsidian-kanban` from BRAT's plugin list, then uninstall Kanban and install it again from Community plugins. Uninstalling deletes Kanban's global settings, so copy `.obsidian/plugins/obsidian-kanban/data.json` first and put it back afterwards. Settings saved in a board stay in that board's file.
>
> **Found a bug?** Report it in [this fork's issues](https://github.com/dev-ankit/obsidian-kanban/issues).

**The Kanban plugin is looking for new maintainers.** Interested? [Read more here.](https://github.com/mgmeyers/obsidian-kanban/blob/main/MAINTAINERS.md)
